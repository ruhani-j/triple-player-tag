# Triple Player Tag

A 3-player browser game built with [p5.js](https://p5js.org/) for a DMII creative coding course.

## How it works

Three players share one screen. Each controls a different shape:

| Player | Shape | Controls |
|---|---|---|
| Player 1 | Circle | Mouse |
| Player 2 | Heart | Arrow keys |
| Player 3 | Triangle | WASD |

**Scoring:**
- Heart or Triangle earns a point each time they touch the Circle for 1 continuous second
- Circle earns a point for every 5 seconds it stays on the canvas without being touched

**Extra controls:** `H` recolors the heart, `T` recolors the triangle, `Y` rotates the triangle.

## Run locally

Open `index.html` in any browser — no server or install needed. p5.js loads from CDN.
